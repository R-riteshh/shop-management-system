# Project Statement

## 1. Problem Statement

Managing inventory manually can be difficult when there are multiple items to keep track of. It can lead to problems such as incorrect item information, difficulty in updating records, and difficulty in finding or removing items.

The purpose of this project is to develop a simple **Inventory Management System** using Python that allows users to manage inventory items through a command-line interface.

The system provides basic operations such as adding, deleting, updating, and viewing inventory items.

## 2. Scope of the Project

The scope of this project includes the basic management of inventory items.

The system allows users to:

- Add new inventory items
- Delete existing items
- Update item information
- View all inventory items
- View a specific item using its item ID
- Exit the application

Each item contains information such as:

- Item ID
- Item name
- Item price
- Item quantity

The project is designed as a simple command-line application using Python. It currently manages the inventory during program execution and does not include permanent database storage.

## 3. Target Users

The target users of this project include:

- Small shop owners
- Store managers
- Inventory staff
- Students learning Python
- Beginners who want to understand basic inventory management
- Users who need a simple command-line inventory system

## 4. High-Level Features

### Add Item

Allows users to add new items to the inventory by entering the item ID, name, price, and quantity.

### Delete Item

Allows users to remove an existing item from the inventory using its item ID.

### Update Item

Allows users to update the name, price, and quantity of an existing item.

### View All Items

Displays all items currently available in the inventory.

### View Single Item

Allows users to search for and display the details of a specific item using its item ID.

### Input Validation

The system uses basic exception handling to handle invalid numeric input.

### Command-Line Interface

The entire application is operated through a simple command-line menu.

## 5. Project Goal

The main goal of this project is to provide a simple and easy-to-use inventory management system while demonstrating fundamental Python programming concepts such as functions, lists, dictionaries, loops, conditional statements, modules, and exception handling.

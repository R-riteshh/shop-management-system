# Inventory Management System

## Project Overview

This is a simple **Inventory Management System** developed using Python.

The project allows users to manage items through a command-line interface. Users can add, delete, update, and view inventory items.

The project is divided into two Python files:

- `project_part_1.py` – Contains the functions for managing items.
- `project_part_2.py` – Contains the main program and menu.

## Features

- Add new items
- Delete items
- Update item details
- View all items
- View a single item
- Exit the application
- Basic input validation using exception handling
